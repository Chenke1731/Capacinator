## 0. 已裁决的模型总纲

### 0.1 交付五层模型
| 层 | 载体 | 语义 | 存储 |
|---|---|---|---|
| 版本规划（B121） | 需求 | 归属——产品版本线，多版本并行 | projects.product_version（已有，自由文本） |
| 交付计划（26.RP1-4） | 需求 | 节奏——季度正式发布（RP1=Q1…RP4=Q4） | projects.release_version（已有，自由文本） |
| 迭代（门户项目12月迭代） | 需求(挂接) | 执行窗口——**唯一日期真相** | iterations 表（新）+ projects.iteration_id |
| 死线 | 需求(派生) | 约束——评估校验用，不占版面 | 现有评估派生 |
| 投入窗口 | 分配(人) | 人什么时候投入 | scenario_project_assignments 起止日期（已有） |

aspiration_start/finish **不启用**；手填日期区间方案作废。

### 0.2 角色时间三角
```
迭代前(今天→迭代开工)   SE：需求分析→清晰可落地→拿到正式 AR 号
迭代内(开工→结束)        MDE：详细设计，与开发结对交付；开发：实现
```
状态机已编码此流水线：designing → 准入·backlog（**转换时记 AR 号**）→ scheduled → in_iteration。
存量 NO_ITERATION_NUMBER 告警即"没拿到 AR 号不该进迭代"的机器表达。

### 0.3 人力双口径（R2 终版）
- **人月给事**（工作量/体积）：代码规模评估的 pm、SE/MDE 粗估。单位人月。
- **占用%给人**（并发/容量）：分配记录 allocation_percentage，People 负载、容量计算的原生口径。
- **换算**：占用% = 人月 ÷ 窗口。系统自动派生为默认值，人可改（现实损耗），改后不强校验一致。
- 推导窗口：SE = 今天→目标迭代开工；MDE/开发 = 迭代窗口。
- **口径统一：工作月**（评审团二号）——全文"人月/月"按 ~21.75 工作日/月；
  窗口时长由自然日区间折算工作日。杜绝自然月/工作月混算的 ~30% 系统性偏差。
- **占用%为写入时点快照**，不随时间自动重算（负载稳定）；弹层每次打开
  显示"当前推导值 vs 已存快照"的差异，人裁决是否更新。

### 0.4 R1 终版：SE/MDE 粗估落设计粗估记录
project_design_estimations 加 `se_estimate_pm`、`mde_estimate_pm` 两列（可空）；
看板就地编辑 = 更新该项目**最新一条**粗估记录。粗估历史、"实际回填校准粗估"
（DESIGN_NOT_BACKFILLED）机制原样生效。不建裸字段。

### 0.5 MDE 跟踪诉求（防爆表）
新开发多，MDE 结对辅助落地。监控面 = 迭代卡上按 MDE 汇总：
**结对项数 · 人月合计 · 强度%（人月÷迭代时长）**，>100% 琥珀。
同一机械对 SE 生效（窗口=开工倒计时）。MDE↔开发不建关系表，从需求派生。强度%为**窗口平均口径**（峰谷不可见，v1 接受并在此声明）。

### 0.6 场景机制 × 迭代挂接（评审团三号发现，已裁决）
iteration_id 定义为**事实字段（非场景化）**：挂迭代是已定的排产事实，
场景（what-if 沙盘）只沙盘**人力分配**（分配表本就带 scenario_id）。
沙盘"换迭代"用"改挂 + 观察告警"替代（改挂写事件注记可回溯）。
将来确需场景化挂接再升关联表，v1 不做。

## 1. 列全景与预算

```
名称(标签+＋AR) | 编号 | 组件* | 状态(徽章›) | 代码规模(KLOC) | 人力(人月)
| SE(人+粗估) | MDE(人+粗估) | 版本规划(B121) | 交付计划(RP+迭代) | 优先级
| 实名投入(人+窗口) | 操作(编辑/删除)
```

| 档位 | 视口 | 行为 |
|---|---|---|
| 全列 | ≥1680 | 13 列全见（预算 ~1374 ≤ 1380） |
| 中档 | 1560–1679 | **藏组件**（编辑兜底=行编辑弹窗含组件字段；筛选仍在），~1282 ≤ 1300 |
| 紧凑 | <1560 | 再藏 编号/交付计划/实名投入 |

SR 聚合行规则（全局）：数值列=子行求和（KLOC/人月/SE/MDE 粗估）；人名列=和+人数
（如 `Σ0.8·2人`），title 列举明细；版本/RP=子行集合去重展示。
**SR 行的 代码规模/人力/SE/MDE 格只读**（评审团三号：改子行才生效，
杜绝聚合行直接改出与"求和"矛盾的值）；交付计划尾行/状态分布同只读。

## 2. G1 名称格构图（事故高发区，规则从严）

常驻单行，从左到右固定顺序：
`[折叠箭头(仅SR行)] 名称文字 · AR计数chip(仅SR行) · 标签chips(≤2) · 告警短词chip`

- **悬停层**：＋AR 幽灵钮（所有需求行可用——修复"仅已分解行有分解按钮"的
  鸡生蛋缺口；SR 行悬停显示为＋AR 追加）；其余悬停只亮底色。
- **截断让位顺序**（空间不足时依次收）：标签折叠为 +N → AR 计数缩为数字 →
  名称文字省略（最后让步）。**告警 chip 永不让位**（最多 +N）。
- 告警挂载位维持名称格（短词 + title 全文），新增告警同位（见 §8）。
- 紧凑档（<1560）标签 chip 不渲染（title 兜底），名称格回到"名称+告警"极简态。
- 标签治理约定：常态 ≤2 枚正交属性；行内 chip 点击 = 按该标签过滤
  （chip 自身 stopPropagation，与格子点击开编辑不冲突）。

## 3. G2 交付计划格（固定两层构图）

- 主行：`26.RP4`（RP 文本，就地可编辑，占位 `26.RP4`）
- 尾行（弱色 mono 11px）：挂了迭代 → `门户12月迭代 · 11-01~11-30`（名+派生区间）；
  未挂 → `未排迭代`（同号弱色占位，可点）
- SR 行尾行 = 子行迭代窗口最早起~最晚止（派生只读，title 列举子行）
- **迭代所属季度由 start_date 派生**（年份.RP+季度），iterations 不存 rp 字段
- 迭代选择弹层：按季度分组的迭代列表（名 + 窗口 + 已装人月），选中即挂接；
  底部内联新建迭代（名 + 起止），与标签新建同模式；零独立管理页依赖
- 改挂迭代 = 写一条生命周期事件注记（"迭代 11月→12月"），零新表（G6）
- **尾行宽度缩写**（评审团四号）：迭代名截至 6 字＋区间
  （`门户项目12… · 11-01~30`，title 全文）——全名约 145px 必超 76-84px 列宽
- **迭代清算**（评审团一号）：迭代 end_date 过后仍挂靠且未交付的需求 →
  行告警 ITER_ENDED_UNDONE（短词"迭代未清"）；不改状态、不自动改挂，
  迭代页过期卡置灰提示处理
- 死线不显示，仅告警

## 4. G3 实名投入格

- 格子：`王工 11-01~12-15`（主投入人 + 窗口）；宽度不足时窗口截为 `11-01~`，
  title 全文；无人 → `— 未投入`
- **主投入口径**：scenario_project_assignments 加 `is_primary` 布尔（迁移）；
  开发侧第一条实名分配默认主投入，弹层可切换
- 弹层四段：①主投入选人（搜索 + 当前负载%警示）②起止日期（默认=迭代窗口）
  ③开发池 ±0.5 步进（池机制收进此处）④次要开发分配列表（可增删）——
  多开发投入的信息去向：看板只显主投入，其余在弹层，明示不隐藏
- SR 聚合 = 子行主投入人数 + 合计强度

## 5. G5 SE / MDE 格

- 格子：`王工 0.5`（人名 primary + 粗估值 mono 次色）；空态 `— 未派`
- 弹层三段（推导式摆在脸上）：
  ```
  ① 这件事工作量： 0.5 人月        （可改，写最新设计粗估记录）
  ② 窗口（派生）：  今天→11-01 迭代开工（SE） / 11-01~11-30（MDE）
  ③ 派给：王工（当前本迭代已占 80%） 占用 50%（=0.5÷窗口，自动，可改）
  ```
- 选人负载警示 = UI 原则 #4（选人必见负载）；占用%写入分配，People 负载自动累计
- 存量粗估记录只有总人月（estimated_design_pm）、se/mde 分量为空时：
  看板显示"—"，不与总值混算；弹层补填分量后生效（评审团三号）
- SE/MDE 的池概念从看板退出（库机制不动）

## 8. 告警总表

存量（不动）：NO_DEV_DEMAND / NO_LOC_ESTIMATE / NO_DESIGN_ESTIMATE /
DESIGN_NOT_BACKFILLED / DELIVERED_NOT_BACKFILLED / NO_ITERATION_NUMBER

新增（全部建议式，计算时机=相关数据变更时）：
| 码 | 触发 | 挂载位 |
|---|---|---|
| ITER_RHYTHM_MISMATCH | 迭代派生季度 ≠ 手填 RP | 行告警 chip（短词"节奏不符"） |
| ITER_OVER_DEADLINE | 迭代窗口末 > 死线 | 行告警 chip（短词"逾期风险"，title 见死线） |
| ASSIGN_AFTER_DELIVERY | 投入窗口末 > 迭代窗口末 | 实名投入弹层内提示 |
| SE_WONT_MAKE_IT | SE人月 ÷ 该 SE 可用强度 > 开工倒计时 | SE 弹层 + 行告警（短词"SE赶不上"） |
| MDE_OVERLOAD | 迭代级：某 MDE 人月÷迭代时长 >100% | 迭代卡 MDE 负载块（琥珀） |
| DEV_NO_MDE | 有开发主投入但无 MDE 分配（新开发交付风险，评审团一号） | 行告警 chip（短词"无结对"） |
| ITER_ENDED_UNDONE | 迭代 end_date 已过、需求未交付仍挂靠（评审团一号） | 行告警 chip（短词"迭代未清"） |

- 063c：`scenario_project_assignments` 加 `is_primary` boolean 默认 false，
  **部分唯一索引**（每 project×scenario 至多一条主投入；应用层仅开发侧设主）
- 063d：种子：MDE 角色；demo：MDE 人员 ×1、门户项目 10/11/12 月迭代 ×3、
  粗估 se/mde 分量、主投入标记、迭代挂接

API：
- iterations CRUD（列表带装载统计：事项数/SE·MDE·开发人月/状态分布/按人汇总）
- projects update 白名单 += iteration_id；se/mde 粗估走粗估记录更新端点
- 看板 payload 切换：kloc/pm（最新评估）、se/mde 粗估（最新记录）、SE/MDE 分配
  （人+占用）、主投入（人+窗口）、迭代（名+窗口）、死线——**后端容量/负载
  计算零改动（计算同权）**；staffing_summary 消费方盘点后退役
- 生命周期：→ in_iteration 转换参数改迭代选择（吸收 iteration_label）；
  存量 label 保留只读不迁移

## 11. 验收场景（用户最终逐条看）

1. 1600 屏：12 列可见（藏组件）零横滚、名称不截断
2. 交付计划：挂 11 月迭代 → 尾行显示名+区间；改挂 12 月 → 事件注记可查
3. SE 弹层：显示"今天→开工"倒计时与 50% 推导；王工负载警示可见
4. MDE：迭代卡显示 王工 3 项·1.2 人月·120% 琥珀
5. 实名投入：选人+日期落库；主投入切换后看板格换人
6. 状态列：任意行单行单胶囊；`›` 一键推进；SR 行显示分布
7. 标签：名称格 ≤2 枚，chip 点击即过滤；管理器可新建/改色
8. ＋AR：未分解行可直接分解（鸡生蛋修复）
9. 告警：节奏不符/逾期风险 chip 出现在构造的违规数据上
10. 迭代页：日历/未排池/就地 CRUD 全通
11. 边界（评审团五号补）：全库无迭代的空态可引导；挂有需求的迭代删除被阻并提示；
    占用%手改后负载按手改值计、弹层显示推导差异；窗口剩 1 个工作日推导不除零
    并提示不可行；SR 行 SE/MDE/人力格只读、改子行生效；过期迭代+未交付需求
    →"迭代未清"chip；有主投入无 MDE →"无结对"chip
