## P0 硬伤

### P0-1 people 页"工作负载"列状态图标全部不可见（11/11 行）

- **支柱**：D4 物理可见 / B 语义透明（负载状态是排产核心读取项，契约规则"选人必须能看到负载"）
- **证据**：`status-indicator` 内 svg 全部 `0×20`——对勾/加人/上升/警告图标整列消失，只剩百分比数字。
  机器检测列出全部 11 行（陈主管 circle-check-big、王开发 trending-up、李后端 triangle-alert、
  其余 user-plus）；浅色深色同坏。
- **根因**：与人力气泡加减号零宽同机制——表格 auto 布局下"工作负载"列（标称 140px）被宽表
  （快捷操作列 330px 等）挤压，`.status-indicator` flex 容器中 svg 无 `flex: none`、min-content=0
  （overflow:hidden），被文字挤到 0 宽；文字保留 min-content 所以百分比还在。
- **修复方向**：`.status-indicator svg { flex: none }`（一行）+ 该列 min-width；顺带全站给
  `svg { flex: none }` 兜底可一次消灭这一类（ Tischbrot 塌陷家族）。
- **为何守卫没拦**：verify-visual 矩阵只有 projects/people/assignments/dashboard 四页，people 页
  **没有塌陷图标断言**（该断言当时只加在 verify-boards 的 projects 页）。守卫矩阵外+断言未跨站。

### P0-2 路线图页名称链接与优先级徽章/类型 chip 重叠

- **支柱**：D5 碰撞
- **证据**：`.project-name-link`（360×44）与 `priority-badge`（"M"）重叠 37×11px、与
  `project-type-compact` chip 重叠 54×7px，**跨行**（名称行块高溢出到相邻行内容）；双主题。
- **修复方向**：名称行容器 overflow/高度失控，参照需求台"盒子防御"（min-height 而非定高、
  子项 flex:none）修；修后路线图 6/7 条对比度违规大概率同区域，一并处理。
