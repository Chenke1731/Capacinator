# UI 生成契约（Generation Contract）

> 定位：**第一版生成时的思考模板**。每条都来自一次真实失败，写代码前过一遍，而不是靠用户截图当测试用例。
> 守卫（verify-boards / verify-visual / lint:ui）是这三层里的最后两层：交付仪式与兜底，不是第一道防线。
> 维护规则：每发生一次"用户看见而我没看见"的失败，把它沉淀成这里的一条维度，而不是只加一条测试。

## 三层防线模型

| 层 | 时机 | 干什么 | 性质 |
|---|---|---|---|
| ① 生成契约 | 写代码前/中 | 本文档 12 维度逐条过 | 前置（已知维度） |
| ② 陌生人渲染仪式 | 交付前，跑守卫前 | 双主题渲染+逐个打开新交互，人眼看 | 前置（未知维度） |
| ③ 守卫 | 交付时 | verify-boards / verify-visual / lint:ui / 单测 | 兜底（查漏补缺） |

## ① 生成契约 12 维度

写任何自定义控件/交互前逐条自问。**其中 1、4 有静态 lint（`npm run lint:ui`），其余靠过单。**

1. **全局规则冲突**：动手前先查 `client/src/index.css` 与 `client/src/styles/design-system.css` 的元素级规则——`button` 有默认 `padding: 0.6em 1.2em / background / border-radius`、`button,[role=button],input…` 有 44px 最小命中。自定义控件必须逐项显式重置自己要覆盖的属性。**定宽（`width:`）按钮的规则块内必须同块写 `padding`**（哪怕 `padding: 0`）——border-box 下未重置的 padding 会吃光内容盒，svg 图标被 flex 压成 0 宽（2026-09-22 人力气泡加减号物理消失事故）。
2. **双主题物理渲染**：新控件在浅色+深色下各渲染一次并亲自看截图。用户用浅色主题——只在深色下自审等于白干。
3. **物理可见**：渲染后确认图标 rect 宽高 > 0、文字与底色肉眼可辨。按钮盒尺寸达标 ≠ 内容可见。
4. **盒子防御**：定宽容器装可变内容 → 改 `min-width` + 子项 `flex:none`，让盒子随字体撑开而不是挤压内容；行级附加信息（告警 chip 等）不塞进定宽构件内部。
5. **两两碰撞**：作用域内可见叶子元素矩形两两不相交（守卫有，但设计时就该保证）。
6. **视口适配**：1600 与 1366 各过一遍——列宽、换行、溢出、隐藏断点（如负责人列 <1440 隐藏）。
7. **可供性**：可交互必须自报家门——hover 淡底 + 铅笔角标、cursor、title。**同页所有编辑点用同一标准；确立新标准时立即回审全部旧编辑点，禁止祖父条款**（人力气泡没铅笔而新三件套有，就是双标漏网）。
8. **语义自明**：数字带单位与标签（FTE、实/池）；编辑控件声明"改什么、步长多少、改了会怎样"；"此处改什么、别的去哪改"一句话说清。作者看得懂不算数，陌生人看得懂才算数。
9. **术语一致**：同一概念在列、气泡、详情页、语言包用同一套词与视觉语言（如"实名/池"两侧点+加粗/弱化的编码处处同构）。
10. **i18n 完备**：新键 zh-CN 与 en-US 同时添加；禁止裸键（`ns.key` 原样出现在界面上）。
11. **交互闭环**：Enter 确认、Esc 取消、点外关闭（气泡）、失败有反馈、成功就地刷新；破坏性操作二次点击确认；同值再点 = 无操作（防误触）。
12. **保存语义**：乐观更新 + invalidate 正确的 query key（注意共享键投毒：写方要 `Array.isArray(payload) ? payload : payload?.data || []`）。

## ② 陌生人渲染仪式（交付闸，跑守卫之前）

在用户主题（浅色）和深色下渲染改动页面，**逐个打开本次涉及的全部交互**（含同页被波及的旧交互），以"第一次见到这个页面的人"视角问三个问题：

1. **看得见吗？**（控件、图标、标签物理呈现）
2. **知道它在改什么吗？**（不看文档能否说出编辑逻辑）
3. **改完有反馈吗？**（值变了/有提示/失败了会怎样）

三个问题有一个答"否"，回到维度清单修，不进守卫环节。

## ③ 守卫（兜底）

- `npm run lint:ui`——静态扫描 CSS 反模式（定宽按钮无 padding 等），生成时可跑，秒级
- `npm run verify:boards`——结构+几何+可供性断言（含图标物理可见、塌陷检测）
- `npm run verify:visual`——像素基线 + axe 预算 + 碰撞，双主题×双视口
- 单测——交互语义与落库

## 已知反模式速查（每条都是一次事故）

| 反模式 | 事故 | 防线 |
|---|---|---|
| 定宽按钮未重置 padding | 加减号零宽物理消失 | lint:ui + verify-boards 塌陷检测 |
| 只在深色主题自审 | 浅色徽章发虚、裸键暴露两轮白干 | 契约②+verify-boards 浅色巡检 |
| 定宽盒子装可变内容 | 告警 chip 溢出压相邻胶囊 | 契约4+碰撞检测 |
| 无标签数字/控件 | "完全没办法知道编辑逻辑" | 契约8 |
| 新可供性不回审旧控件 | 人力气泡双标漏网 | 契约7 |
| tooltip 当唯一说明 | 编辑模型只有悬停才可见 | 契约8（说明要常驻或即时可见） |
